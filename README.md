# iOS Launcher
## Get the APK with GitHub (no Android Studio needed)
1. Create a GitHub repo and upload ALL files in this folder (including the hidden `.github` folder).
2. Open the repo's **Actions** tab -> "Build APK" runs automatically (or press "Run workflow").
3. When it turns green, open the run, download **IOSLauncher-debug-apk** (zip) at the bottom, unzip, install `app-debug.apk`.
## Set as default
Press Home -> iOS Launcher -> Always (or Settings > Apps > Choose default apps > Home app).
## Use
Long-press the home screen = icon appearance & hidden apps. Swipe down = Spotlight. Swipe past last page = App Library.
